# Licensing and artifact policy

OpenRealtime separates software, documentation, and research fixtures so that
reuse rights are explicit:

- Source code, schemas, configuration, and scripts: MIT License. The complete
  license text is in [`LICENSE`](LICENSE).
- Project documentation, including `README.md`, `CHANGELOG.md`, and `docs/`
  (the historical v1 plan now lives at `docs/openrealtime-v1-plan.md`):
  [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
- Original golden traces, recorded images, and contract fixtures, which live in
  the `testdata/` directory of the package that uses them:
  [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). This
  does **not** cover the speech fixtures, which are described immediately below.
- Speech fixtures under `bench/meeting/testdata/audio/` and
  `bench/realtimecu/testdata/audio/`: **no onward grant from this project.**
  They are synthesised speech, generated locally on this project's own GPU with
  Fish Audio, and they are therefore that model's output rather than material
  this repository is in a position to place in the public domain. The Fish Audio
  Research License Agreement described below permits research and
  non-commercial use and requires a separate written license for commercial use;
  its conditions reach the output and apply independently of this repository's
  MIT code license. Anyone reusing these twelve files should read that
  agreement for the revision they intend to rely on rather than treat the
  fixtures as unencumbered.
- Generated OpenAI OpenAPI-derived schema and registry files: MIT, with source,
  revision, hash, and license text in `third_party/openai/NOTICE.md`.

Files that name a different license retain that license. Third-party data,
model weights, generated voices, and provider output must not be added without
an entry in the artifact inventory that records origin, license, consent or
other lawful basis, transformations, and cryptographic hash.

The artifact inventory for the speech fixtures is the `fixtures.json` beside
each set: [`bench/meeting/testdata/fixtures.json`](bench/meeting/testdata/fixtures.json)
and [`bench/realtimecu/testdata/fixtures.json`](bench/realtimecu/testdata/fixtures.json).
Each records the generating model, the endpoint it ran on, the conversion
applied, and a SHA-256 and duration for every file; the Meeting manifest also
carries the spoken text of each segment, which was never recorded for the
Realtime-CU set. The checked-in bytes and those hashes are the benchmark input:
provenance there is informational and nothing regenerates a fixture during a
run.

Two things in those manifests are honestly unknown rather than omitted. The
model revision was not recorded when either set was authored, and the
Realtime-CU utterance text was not written down. Neither is recoverable from
the tree or its history.

An earlier version of this paragraph read "The M0 audio fixture is procedurally
generated by this project. It contains no human voice, performer identity,
imported sample, or model output." That described `tests/fixtures/m0-tone.wav`,
a generated tone removed with the original harness, and it never covered the
fixtures that exist now - which are model output, and are licensed accordingly
above.

The compatibility example in `examples/sdk-client/` installs OpenAI's
`@openai/agents-realtime` client from npm at test time and builds a browser
bundle from it. Neither the package nor the bundle is redistributed here: the
directory contains the test that drives the published client and nothing of
the client itself, `node_modules/` and `dist/` are excluded from the
repository, and the example is skipped entirely when the package is absent.
The package is MIT-licensed by OpenAI; installing it is the reader's act
rather than this project's, and no Go build, test, or analysis path depends on
it.

The optional native macOS browser bridge installs `browser-use==0.12.6` from
PyPI with `uv`. browser-use is MIT-licensed, copyright 2024 Gregor Zunic. The
dependency and its transitive Python packages are not vendored in this
repository or embedded by a normal Go or Swift build;
`macos/prepare-browser-use.sh` is the operator's locked installation step and
places the environment in Application Support. The app bundle contains this
project's small JSON-lines adapter, manifest, and lockfile and invokes the
installed package offline for its DOM selector map, set-of-mark image renderer,
and browser action implementation. Deployers distributing that environment
must carry browser-use's MIT notice and review the notices of the resolved lock
set.

The τ-Voice benchmark is referenced through an external manifest only. Its
`tau2-bench` source repository states the MIT License at pinned revision
`c3398666e6559e3a063da3fc04b5acf7f941464e`; no upstream code, task data,
voices, or generated artifacts are redistributed here. ElevenLabs personas,
provider output, and any downloaded task assets require their own provenance
and terms review before publication.

## Live-model experiment notice

The repository does not redistribute the Qwen3-ASR, Qwen3-30B-A3B-FP8, or Fish
Audio S2-Pro weights used by the 2026-08-18 live experiment. Runtime caches are
outside the repository and benchmark reports contain hashes/timings rather than
weights or credentials.

The locally retrieved Fish S2-Pro snapshot identifies the **Fish Audio Research
License Agreement**, last updated March 7, 2026. It permits research and
non-commercial uses under its terms and states that commercial use requires a
separate written license. Its attribution, acceptable-use, redistribution, and
other conditions apply independently of this repository's MIT code
license. Before reproducing or deploying any live condition, operators must
read the exact license shipped with each selected weight revision and verify
service/API terms at the time of use. A model named in documentation is an
experimental condition, not a grant of model rights.
