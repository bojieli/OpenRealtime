# Licensing and artifact policy

OpenRealtime separates software, documentation, and research fixtures so that
reuse rights are explicit:

- Source code, schemas, configuration, and scripts: Apache License 2.0. The
  complete license text is in [`LICENSE`](LICENSE).
- Project documentation, including `README.md`, `PLAN.md`, and `docs/`:
  [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
- Original audio fixtures and golden traces in `tests/fixtures/`,
  `tests/golden/`, and `benchmarks/*/reference/`:
  [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
- Generated OpenAI OpenAPI-derived schema and registry files: MIT, with source,
  revision, hash, and license text in `third_party/openai/NOTICE.md`.

Files that name a different license retain that license. Third-party data,
model weights, generated voices, and provider output must not be added without
an entry in the artifact inventory that records origin, license, consent or
other lawful basis, transformations, and cryptographic hash.

The M0 audio fixture is procedurally generated by this project. It contains no
human voice, performer identity, imported sample, or model output.
