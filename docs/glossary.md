# Glossary

**Backchannel** — A short listener signal such as acknowledgement that does not
claim the main speaking turn.

**Capture time** — Monotonic media-ingress time associated with an observation.
It is distinct from the later time at which a component emits an event.

**Canonical trajectory** — The single ordered working memory consumed by fast
and slow continuations. It contains observations, reusable reasoning when
available, assistant content, non-executable tool proposals, executable tool
calls/results, and audible-commit facts.

**Commit horizon** — The boundary between replaceable planned output and audio
already played to the user.

**Endpointed cascade (B0)** — A pipeline that waits for detected end of user
speech before final perception, response generation, and synthesis.

**Continuation** — One model invocation that consumes a prefix of the canonical
trajectory and appends reasoning, assistant content, or authority-typed native
call output to it.

**Fast continuation** — A deadline-bounded continuation using a local instruct
model or minimal thinking. It emits ordinary assistant content or remains
silent, and may append a structured non-executable tool proposal; it is not a
separate agent or a structured action classifier.

**Heterogeneous interleaved thinking** — Successive portions of one trajectory
generated by models with different latency, family, or reasoning-budget
profiles.

**Incremental hypothesis** — A perception result with a stable prefix, an
unstable suffix, timestamps, uncertainty, and a monotonic revision identity.

**Microturn** — A bounded opportunity to update belief or act while an
interaction is still unfolding. It is a scheduler event, not necessarily an
audible utterance or a mandatory provider invocation.

**Native speech system (N1)** — A model that consumes and generates audio in
one realtime interaction path without requiring a text-only component boundary.

**Perceived responsiveness** — User-observed progress and appropriateness,
which includes but is not reducible to first-audio latency.

**Response candidate** — A replaceable semantic action derived from a named
evidence revision and guarded by confidence, risk, and validity conditions.

**Revision-safe preparation** — Private pre-endpoint continuation work that
keeps at most one latest-revision chain active. A chain is eligible only when
its complete provider-visible root matches final input, and each stage replays
only when its exact canonical request also matches. Private speech and tool
effects are forbidden.

**Temporal launch pacer** — A content-independent compute policy that enforces
a minimum interval between speculative launches of one stage. It can cancel an
obsolete wait before provider invocation, but exact final commit bypasses the
remaining delay. It never decides whether slow reasoning is semantically
needed.

**Safe point** — A trajectory boundary at which queued events can be appended,
models can be substituted, or cancellation can take effect without inventing
an impossible ordering inside a completed item.

**Slow continuation** — A higher-reasoning continuation that inherits the fast
trajectory prefix and may append reasoning, tool calls/results, and further
assistant content. Its output is part of the same rollout, not advice from a
second agent.

**Tool proposal** — Validated structured working state produced by a
proposal-authority continuation. It describes a possible tool name and
arguments but cannot execute and cannot have a tool result attached.

**Stable prefix** — The portion of an incremental hypothesis declared unlikely
to change under a stated provider contract. It is evidence, not committed
truth.

**Trace** — An append-only, schema-versioned, causally linked event stream used
as the source of truth for replay, analysis, and visualization.

**Turn gap** — Time between the measured end of one speaker’s contribution and
the start of the next relevant semantic audio. Negative values represent
overlap.
