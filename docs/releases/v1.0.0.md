# OpenRealtime v1.0.0

Released 2026-08-17.

This release completes the M0–M7 open reference program and freezes the
component API at `github.com/bojieli/OpenRealtime/api/v1`.

## Compatibility

- OpenAI protocol boundary: 133 pinned profile/direction definitions, 66 unique
  wire event names, and the complete 178-definition nested schema closure.
- Profiles: GA Realtime, GA transcription, GA translation, and legacy beta.
- Strict behavior: exact JSON wire names, lossless unknown-message decoding,
  explicit profile/direction validation, required-field enforcement, and no
  research metadata injected into wire messages.
- Stable provider roles: perception, cognition, speech, fast decision, and
  deliberation, with versioned descriptors and context cancellation.

Run `./scripts/reproduce_m7.sh` for the complete protocol, provider, benchmark,
example, race, vet, formatting, and byte-reproduction gate.

## Scope

“Protocol compatible” describes the event codec/schema boundary and validated
causal traces. This repository does not claim to be an OpenAI-hosted server or
to reproduce authentication, WebSocket/WebRTC/SIP transport, model behavior,
voices, rate limits, or service-side timing. Native provider and human study
rows remain explicitly not run.
