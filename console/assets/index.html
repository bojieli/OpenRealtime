Press Connect and talk. The agent hears you continuously — there is no push to talk, because deciding when a turn ended is the server's job.

Sent as session.update on connect, and again whenever you press Apply. The openrealtime key is the extension negotiation; remove it to see the session degrade to the base protocol.

First audio is measured from the endpoint the server reported to the first audio frame that reached this page, which is the wait a person actually experiences. On WebRTC the audio arrives on the media track, so that number is the track's first packet.
